# Merge Tactics Next-Pick Helper

A lightweight Clash Royale **Merge Tactics** helper built with Next.js.

## What it does

- Displays a troop catalog with each troop's two traits and elixir cost.
- Lets you select your current roster and track each selected troop's current star level (1★–4★).
- Lets you choose a tactical optimization path:
  - Goblin Tempo
  - Assassin Backline Dive
  - Economy & Denial
- Suggests the best next units based on tactic-specific decision trees.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
```
